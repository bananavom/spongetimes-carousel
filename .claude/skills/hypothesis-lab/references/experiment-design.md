# 실험 설계 — 단일 계정에서 정직하게 비교하는 법

인스타그램 한 계정에서는 같은 콘텐츠를 두 집단에 동시에 보여주는 진짜 A/B 테스트가 불가능하다.
그래서 우리가 쓰는 것은 **준실험(quasi-experiment)** 3종이다. 완벽하지 않다는 걸 알고 쓰는 것과
모르고 쓰는 것의 차이가 데이터 운영의 수준을 가른다.

## 비교 설계 3종

### 1. baseline — 롤링 베이스라인 비교 (기본값)

실험 포스트의 지표를 **최근 4주 같은 포맷 포스트들의 평균**과 비교한다.

- 쓰는 때: 실험 포스트가 1개뿐일 때. 가장 흔한 상황.
- 강점: 항상 가능하다. 베이스라인은 `baseline.json`에 이미 있다.
- 약점: 계정 상태(팔로워 수, 알고리즘 시즌성)가 4주 사이 변했을 수 있다.
- 규칙: 반드시 **같은 포맷끼리** 비교한다. 캐러셀을 릴스 평균과 비교하면 무의미하다
  (포맷마다 도달 구조 자체가 다르다).

### 2. paired — 짝비교 (가장 강한 설계)

같은 주에 **실험 변수만 다른 포스트 2개**를 발행해 서로 비교한다.
예: W1에 단색 배경 캐러셀 1개 + 실사 스크린샷 배경 캐러셀 1개.

- 쓰는 때: 주 2회 발행 리듬을 그대로 실험에 쓸 수 있을 때. 가능하면 이걸 선택하라.
- 강점: 계정 상태·시즌성이 거의 동일한 조건에서 비교된다.
- 약점: 주제 강도가 다르면 배경이 아니라 주제가 결과를 만든 것일 수 있다.
- 규칙: 두 포스트의 **주제 매력도를 최대한 비슷하게** 잡고, `topic` 컬럼에 기록한다.
  발행 요일·시간대도 최대한 맞춘다 (예: 둘 다 평일 저녁).

### 3. prepost — 전후 비교

변수 도입 전 기간 평균 vs 도입 후 기간 평균.
예: "매거진 문법" 4주 vs "작업노트 문법" 4주.

- 쓰는 때: 한 번에 되돌리기 어려운 큰 전환(문법 전체 변경 등)을 평가할 때.
- 강점: 여러 포스트가 쌓이므로 개별 포스트의 운이 평균화된다.
- 약점: 시간이 흐르며 팔로워 수·계정 신뢰도·시즌이 함께 변한다. 가장 교란에 약한 설계.
- 규칙: 전/후 기간의 팔로워 수를 함께 기록하고, 절대값 대신 **율(rate) 지표**로 비교한다.

## 교란변수 체크리스트

실험 설계 시 아래를 확인해 가설 카드에 기록하라. 판정(모드 ⑤)에서 이 목록을 다시 본다.
교란이 결과를 설명할 수 있으면 판정은 `판단불가`가 될 수 있고, 그것이 정직한 결론이다.

| 교란변수 | 확인할 것 | 완화 방법 |
|---|---|---|
| 게시 시간대 | 실험군과 대조군의 발행 시각이 비슷한가 | 발행 시간을 고정하라 (예: 평일 19~21시) |
| 요일 | 주말/평일 차이 | 짝비교 시 같은 요일대에 발행 |
| 주제 강도 | 한쪽 주제가 원래 더 매력적이지 않은가 | `topic` 기록, 짝비교 시 주제 균형 |
| 팔로워 드리프트 | 비교 기간 사이 팔로워 수 변화 | `follower_count_at_snapshot` 기록, 율 지표 사용 |
| 외부 유입 이벤트 | 스토리 리셰어, 공유회 홍보, 크루 개인 계정 공유 | `notes`에 기록. 있었으면 도달 해석 주의 |
| 스냅샷 시점 | 24h 행끼리, 7d 행끼리만 비교했는가 | 다른 스냅샷끼리 절대 비교 금지 |

## 최소 표본에 대한 솔직한 태도

주당 포스트 2~3개 규모에서 통계적 유의성은 애초에 기대할 수 없다.
그래서 이 OS의 판정은 "유의미하다/아니다"가 아니라 **"차이의 크기 + 반복 여부"**로 본다:

- 1회 결과는 방향 신호일 뿐이다. 임계값을 크게 넘어도(예: 저장률 2배) "지지(1회)"로 기록하고,
  **같은 변수로 한 번 더 반복**해 재현되면 그때 확정 신호로 취급한다.
- 차이가 ±20% 이내면 표본 1~2개로는 운과 구분할 수 없다 → `판단불가` 쪽으로 기울여라.
- 발표 자료의 원칙 그대로: **통하면 반복, 안 통하면 다음 가설로.**
