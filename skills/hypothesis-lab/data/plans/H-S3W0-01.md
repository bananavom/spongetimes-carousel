# 콘텐츠 기획 — H-S3W0-01 「가두리망 캐러셀」

- **가설**: 자기 제품을 파는 1인 사업자에게 '광고비는 그대로인데 가입 단가만 10분의 1로' 훅으로
  1차 전환 구조를 도식화한 캐러셀을 보여주면, 저장률이 베이스라인 캐러셀 저장률의 2배 이상일 것이다.
- **실험 변수**: 표지 정보 노출도 = 개념 도식 통째 노출 / **목표 지표**: `saves` / **기준**: `baseline × 2.0`
- **발행자**: 봄 · **유형**: 인사이트 · **구성**: 표지 1 + 본문 5 + CTA 1 · **주차**: 미배정

기획안(도식·미리보기 포함): https://claude.ai/code/artifact/e6bbba6d-00ba-4f9f-ae40-23782f6f9b09

## 설계 원칙 (하나라도 빠지면 실험군이 아니다)

1. **표지에서 정보를 아끼지 않는다** — 3중 가두리망 도식을 표지 이미지 슬롯에 올린다.
   도식을 2번 장으로 미루면 실험 변수가 사라진다.
2. **마지막 본문이 체크리스트다** — 저장은 "나중에 다시 확인하고 싶은 정보"에서 나온다.
3. **숫자는 배수로만 쓴다** — 절대 금액·절대 인원 금지. 아래 변환표가 정본.

## 3중 가두리망 도식 (표지 + 06번 공용)

- 동심원 4겹. 바깥부터 `1겹 알림 신청` → `2겹 카카오 채널` → `3겹 스토어 알림`,
  중심 = **메시지를 보낼 수 있는 상태**(= 1차 전환).
- 좌측에서 "광고로 유입된 방문자" 실선 화살표가 세 겹을 통과해 중심으로 들어가고,
  "그물이 없으면 그대로 이탈" 점선 화살표가 밖으로 빠진다.
- 규격 1080×1080 투명 PNG. 중심 원 `#FFE67A`, 선·텍스트 `#1A1F36`.
- 표지 배치: 우하단 크게(도식) + 좌하단 작게(봄 캐릭터, size 240 이하).

### 02 · HERO — 문제 정의

| 필드 | 값 |
|---|---|
| `heading` | 광고비를 더 써도 \ 매출이 안 늘 때 |
| `subcaption` | 문제는 유입이 아니라 그다음이었다 |
| `heroBody` | 유입 한 명을 데려오는 값은 커피 한 잔의 몇십 분의 일. \ 그런데 첫 구매 한 명을 만드는 값은 그 수십 배가 된다. \ 마진이 얇을수록, 그 한 명은 팔아도 남는 게 없다. |
| `category` | CONVERSION |
| `circle` | on · 우상단 · 중 · 원 |

> CAC 소재(②)를 별도 콘텐츠로 내지 않는 대신 도입부 한 장으로 흡수했다.

### 03 · HERO — 재정의 (핵심)

| 필드 | 값 |
|---|---|
| `headingPill` | on · '핵심 개념' · dark |

| `heroBody` | 1차 전환 = 메시지를 보낼 수 있는 상태. \ 사지 않아도 된다. 연락할 수만 있으면 된다. \ 한 번 연결되면 그다음 설득은 광고비가 아니라 메시지로 한다. |

### 04 · FLOW — 3중 가두리망

| 필드 | 값 |
|---|---|
| `heading` | 에어라인 마켓의 \ 3중 가두리망 |

| `flow[1]` | 2겹 · 카카오 채널 / 친구 추가 한 번으로 매일 말 걸 수 있는 창이 열린다 |
| `flow[2]` | 3겹 · 스토어 알림 / 플랫폼 안에서 다시 만날 수 있는 마지막 그물 |
| `flow[3]` | off |

### 05 · GRID HERO — 미끼 4종

|---|---|

| `grid[2]` | 야간 동의 / 야간 수신에 동의하면 애플워치 추첨 — 가장 비싼 권한을 경품으로 산다 |
